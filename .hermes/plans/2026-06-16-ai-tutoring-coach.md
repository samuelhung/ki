# AI 学习教练方案

> 2026-06-16 讨论记录，待后续启动

---

## 核心命题

从「静态内容库」变成「AI 学习教练」。用户一句话（"上到第15课了"），AI 综合判断应该提供什么练习：课时巩固、间隔复习、薄弱补强、还是综合运用。

---

## 三层架构

```
用户输入层 → AI 学习教练（推理层）→ 题目生成层 → 作答+批改+记录
```

### 推理层输入

- 用户进度（课/单元/学期）
- 练习历史（做了什么题、正确率、用时）
- 薄弱点画像（哪些知识点错误率高）
- 艾宾浩斯间隔（各课最后一次练习时间）
- 教材结构（当前课文类型、单元语文要素）

### 推理层输出

- 个性化练习方案
- 每道题标注训练意图（知识点+难度+来源）

---

## 每课结构

```
课文解读（已有）→ 字词积累（新）→ 课后练习（新）→ 朗读指导（新）
```

## 单元整合

```
单元知识地图 → 语文园地/习作 → 单元综合练习 → 单元评估报告
```

## 知识点体系

字（识字方法/写字规范/查字典）→ 词（理解/搭配/成语）→ 句（句式/修辞/病句）
→ 阅读（提取/概括/推理/鉴赏）→ 写作（描写/结构/表达）→ 口语交际

---

## 练习数据来源（关键设计决策）

| 学科 | KI 线上做 | 纸笔+家长录入 | 远期 |
|------|-----------|---------------|------|
| 语文 | 选择题/判断/连线/阅读理解选择 | 看拼音写词/默写/作文（打字=作弊） | 拍照OCR手写批改 |
| 数学 | 选择/判断/填空/结构化拆解题（低年级） | 应用题完整解题过程/竖式/几何 | 拍照OCR解题步骤识别 |

### 家长录入设计

极简点选："错了几个 / 哪种题型 / 大致错因"，5秒完成，不逐题录入。

### 数据表

```
study_practice_records
  material_id, lesson_index, practice_type,
  correct_count, total_count, error_details(JSON),
  duration_seconds, source(ki_online|parent_input|photo_ocr),
  created_at
```

---

## 优先级

| P0 | 练习题生成引擎 + 练习历史记录 |
| P1 | AI 学习教练 + 薄弱点画像 |
| P2 | 自由诊断（"作文写不长"→AI诊断+训练方案）+ 艾宾浩斯提醒 |

---

## 与现有系统关系

```
现有：教材上传 → 解读生成 → 逐课浏览
新增：学习教练 → 进度追踪 → 智能推荐 → 动态练习 → 错题积累 → 薄弱画像
```

教材结构 lessons_json 作为 AI 知识底座，结合练习历史做推荐。无练习历史时退化为纯进度推荐，功能降级但不失效。
