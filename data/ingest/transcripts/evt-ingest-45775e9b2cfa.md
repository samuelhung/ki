易沃观察2026年3月3日。今天这期想和大家聊一聊高盛近期更新的，正文长达39页的报告，名为中国互联网导航顶级 AI 应用追踪。他把模型 token 智能体和超级入口串成了一条主线，对2026年国内 AI 算力和应用的节奏给出了相对完整的一套看法。报告在会员空间可以获取。主线信息已植入决策外脑，我们可以先从最底层的模型说起。最近一个比较反直觉的现象是，国内大模型不光在性能上持续贴近海外头部，在性价比上也走出了一条更陡的曲线。在第三方 API 聚合平台 OpenRouter 上，2月份这几周使用中国 AI 模型的 token 整体上已经第一次压过了美国模型。背后是 Minimax M2.5，月之暗面的 kimi K2.5。智谱 GLM 5这一批新模型集中上线，在综合能力上缩小差距的同时，把上下文窗口拉到了百万级 token 定价做到美国旗舰模型的5%~10%。高盛的观点是，现在决定 token 往哪边走，不再是单纯看谁最强，而是看在合格效果之上，谁更便宜，更好调度。中国模型就是顺着这条效率曲线，在不断拿份额。换个说法，模型层面正在从堆性能和比规模，转向比每一份算力能产出多少有效工作量。报告里也特别提到，包括 Deepseek 在内的一些国内团队，在底层架构上继续沿着算力解耦这一条路往前走，通过对存储带宽瓶颈做双路径优化。把记东西和算东西拆开处理，让静态知识放到更便宜的存储里，宝贵的 GPU 只专心做推理。这样在不大幅加硬件的前提下，把大模型的效率再往上推了一节。这和此前说到的 TAK 逻辑是连在一起的，本质上都是在用算法去对冲算力成本。如果把视角从模型本身挪到谁在用模型，那企业端的 token 爆发就是高盛这次调整判断的关键一环。报告引用，Foster 和Sullivan的数据，二零二五年下半年，中国企业日均 token 消耗，从上半年的十点二万亿，跳到了下半年的三十七万亿，半年时间增幅是百分之二百六十三。这个节奏已经不是小范围试水，而是明显的台阶式上移。在这当中，通义千问、豆包和 Deepseek 合起来拿下了超过七成的企业 token 份额。通义千问的占比从17.7%拉到了32.1%。豆包从14.1%升到21.3%，Deepseek 从10.3%走到18.4%。高盛而是把自动编码流程机器人这种任务，真正在日常业务里跑起来了。Token 消耗开始和真实业务规模挂钩。在这样一组数据的支撑下，高盛顺势把对阿里云的增长和资本性投入预测整体抬高。报告给出的判断是，阿里云在二零二五年十二月和二零二六年三月这两个季度，收入同比增速有望分别到百分之三十八和百分之三十七，比此前的共识要乐观不少。配合这一点，他把阿里三年期的资本性投入规划从3800亿元人民币往上调到了大概5130亿元人民币。简单理解就是企业级 token 越多的沉淀在某几家云平台上。这几家的云与数据中心业务，未来几年就越有底气把钱继续砸在算力和基础设施上。往上走一层，就是春节期间在 c 端上演的那场 AI 超级入口之战。QuestMobile 的跟踪显示，今年春节，字节的豆包在2月16日的单日 dau 冲到了大约1.45亿。通义 APP 的峰值在7400万左右，元宝也看到了大约4100万的高位。几家头部平台一边扔补贴，一边推运营活动，就是希望把 AI 助手变成各自生态里的新入口。高盛认为，谁能把这个入口坐稳，关键不在于谁的聊天更像人，而在于三个能力，能不能真正帮用户干活，能不能顺畅街上购物、外卖这些交易场景。还有能不能用社交和推送，把 AI 嵌到用户的高频日常里。这里面还有一个和海外很不一样的地方，就是国内 2C 聊天机器人大多还是免费用的人多，付费的少。海外很多是订阅收费。中国更像是在为下一步的商业化打地基。高盛的判断是，随着 AI 助手慢慢占据搜索和应用分发的一部分入口，广告预算很可能会从传统的关键字竞价和信息流。迁移到围绕智能体和深层次答案的 AEO 和 GEO 方案上。谁在新的入口里掌握主动权，谁就有可能在广告 roi 的分配上拿到更多话语权。叠加 AI 在内容生产端带来的降本增效。高盛还是把云与数据中心、游戏与娱乐、 AI 模型这三条子行业主线放在了重点观察的位置。时间拉长一点，这份报告还试图用一套数字去回答一个更大的问题。就是基础模型这一层到底有多大的收入空间。按他引用的 cic 数据看，全球基础模型订阅和 api 的收入池从二零二三年的四十亿美元增长到二零二四年的一百零七亿美元之后。如果按88%的年复合增速往前推，到2030年会放大到4720亿美元。其中侧重文本和智能体的模型有机会从2025年成长到二零三零年的三千三百二十亿美元。多模态视频，图像和音频相关的模型，则是从九十亿美元走到一千三百九十亿美元。这些数字只算模型本身的订阅和调用，并不包括平台层和广告层的二次放大效应。在这样的背景下，中国模型厂商的位置就显得比较微妙。一方面，今年以来，智谱、MiniMax 等国内 AI 模型公司的估值出现了明显抬升。部分独立玩家在二级和一级市场的估值区间已经可以和海外头部公司形成某种程度上的对照。另一方面，在 OpenRotor 这类平台上的 token 使用排名，中国模型已经能和全球头部模型同场竞技。再结合人工智能评测平台的数据，可以看到中国模型在关键任务的解决率上，大概比美国最新一代 SOTA 模型低10个百分点左右。但每解决一个问题的成本要低不少。整体呈现的是性能略逊一筹，成本优势明显的组合。高盛认为这种性价比结构给了中国模型在全球基础模型市场里继续提升份额的空间，但能不能兑现？还要看后面几轮迭代和资源投入的节奏。报告也没有回避中美在算力和生态上的差距。一头是美国厂商在下一代通用 GPU 架构上的领先。黄仁勋在今年 CES 上提到。新一代鲁宾架构在推理性能上相对 Blackwell 有望提升5倍左右，在训练性能上提升3.5倍左右，同时进一步拉低单位算力成本。这意味着算力端的代际跃迁还在不断加速。另一头是中国模型厂商在资金、产能和软件生态上的短板，要通过架构创新和国产算力持续投入，把这条差距线尽量压在一个可控区间内。这件事会在未来几年不断被市场重新定价。如果再把目光抬高一点，看宏观和政策。报告的判断是，我国在电力成本和基础设施上的优势，会在算力时代继续被放大。配合东数西算等工程。国内在建设绿色算力网络上的节奏，有望形成自己的节拍。与此同时，围绕本土芯片和 AI 基础设施生态的支持性政策大概率会延续甚至强化。但像 H 二百这样的高端芯片，能否稳定进入中国市场？依然存在不小的不确定性。高盛的表述也比较谨慎，只是强调这会改变中美模型之间的差距走向，而不会单独决定这条产业赛道的成败。在这样的铺垫之下高盛给出了一个面向2026年的六点提示。先看第一条，是广告和营销预算的重新分配。随着 AI 生成答案和智能体入口的渗透，预算会逐步从传统投放方式转向围绕回答质量和用户转化效果的新一代 AEO 和 GEO 方案。接着是大模型本身的眼镜，长上下文、多模态、代码和智能体能力还会在今年继续迭代，国内厂商有机会在部分场景里拉近甚至反超。第三个方向落在 c 端入口。高盛认为今年可能是 To C 助手和 AI 超级入口真正落地应用的一年。这会倒逼互联网平台在资本性投入和运营费用上继续加码。短期利润承压，长期则是新质之争。再往下是芯片和算力的博弈，能不能拿到下一代芯片资源，会直接改变中美模型在推理成本曲线上的相对站位。国内产业链需要在自主可控和全球协同之间找到一个动态平衡。第五个点，关乎基础模型行业的形态。高盛的判断是，最终大概率会走向开源和闭源并存的格局。这也就意味着独立模型公司和大型互联网平台之间是单纯的竞争，还是有更深的分工和协同，现在还远远没有定性。最后，高盛把中国企业级 token 需求的台阶式上移。看作是未来几年云与数据中心子行业的重要趋势参考之一。认为这条线在2026年之后还有继续抬升的空间。另外一方面，风险提示上，一是如果国内模型厂商在资金和人才上的投入节奏明显慢于美国头部玩家。而英伟达等又持续通过新架构拉开效率差距，中美模型在综合能力上的差距有可能再度拉大， token 分配格局也会随之变化。二是商业化节奏。当前国内 To C 聊天机器人以免费为主，广告和营销的变现路径还在探索中。如果用户习惯迟迟无法建立，或者未来对广告形态的监管进一步趋严。盈利时间表就会往后推。三是监管和合规，尤其是教育、金融这类强监管行业，一些小的政策微调，都可能对业务模式产生放大效应。站在国内专业投资者的角度，这份报告最有价值的地方。不在于给出某一个答案，而是在于提供了一整套可以反复对照的坐标系。一头是底层模型的性能和 token 使用数据，另一头是云业务收入和资本开支的节奏。中间再连上 c 端入口和企业端流程再造这两条线，就能大致勾勒出一条从算力解耦到应用落地的传导路径。对于习惯做中长期配置的资金来说，更重要的可能不是在板块之间短期切换，而是盯住 token 资本开支和时间占用这些高频数据。看哪些业务真的走到了产能、订单、现金流这一整套闭环上。受限于篇幅，原文中关于中美 Token
