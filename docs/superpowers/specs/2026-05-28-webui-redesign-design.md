# WebUI 重构设计文档

日期: 2026-05-28
状态: 已确认

---

## 背景

当前 WebUI 存在三个核心问题：

- **A 导航虚假**：左侧链接只是锚点跳转，不是真正的页面切换。URL 不变、不支持浏览器后退
- **B 信息密度失控**：所有模块堆在一个长滚动页，无主次、无层次
- **C 视觉语言不统一**：表单、列表、卡片混用，交互模式不一致，空状态无引导

## 设计目标

1. React Router 实现真正页面切换（URL 驱动）
2. 每个页面信息密度适中，只展示该模块内容
3. 统一组件风格：按钮三层层级、统一输入控件、列表/卡片/空状态规范
4. 保持现有暗色 teal 主题，不引入第三方 UI 库
5. 全中文界面

## 路由结构

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | 仪表盘 | 首页，四指标卡片 + 最近 5 条事件预览 + 快捷操作 |
| `/ingest` | 内容摄入 | 两个 Tab：抖音分享 / 文件上传 |
| `/events` | 事件列表 | 全部事件，支持按状态/来源/主题筛选 |
| `/sources` | 信息源 | RSS 源管理列表 |
| `/digest` | 每日摘要 | 最近一期摘要，markdown 渲染 |
| `/candidates` | 行动候选 | 待审核列表，状态变更操作 |

## 布局

- **左侧 sidebar**：窄栏（~64px），仅图标 + hover tooltip，当前页高亮
- **右侧内容区**：React Router `<Outlet>`，页面独立渲染
- **顶部状态栏**（可选后续迭代）：面包屑 + 通知

## 组件规范

### 按钮
- 主要操作：teal 底色 + teal 边框 (`rgba(20,184,166,0.18)`)
- 次要操作：blue 底色 + blue 边框 (`rgba(59,130,246,0.16)`)
- 幽灵按钮：透明底色 + gray 边框
- 统一圆角 999px pill、统一 padding

### 输入控件
- 文本输入/textarea/select 统一边框 `rgba(148,163,184,0.22)`
- 统一圆角 10px、统一 focus ring (teal)
- placeholder 颜色 `#6b8b83`

### 列表项
- 统一圆角 8px、边框 `rgba(148,163,184,0.12)`
- 状态标签统一 pill 形状 (`border-radius: 999px`)

### 指标卡片
- 标题前加语义化 emoji 图标
- 圆角 10px、数字大字号

### 空状态
- 始终包含：图标 + 标题 + 引导文案
- 居中布局、边框 dashed

### Tags / 状态
- 统一 pill 形状、统一颜色映射：
  - 新增 → teal
  - 处理中 → blue
  - 失败 → red
  - 已处理 → gray

## 页面详细设计

### 仪表盘 `/`
- 四格指标卡片（今日新增📰、高优先级⚠️、待处理📋、信息源📡）
- 最近 5 条事件预览列表（点击跳转 /events）
- 快捷操作按钮组：提交抖音链接 / 上传文件 / 手动采集 RSS / 生成摘要

### 内容摄入 `/ingest`
- 两个 Tab 切换：「📱 抖音分享」「📁 上传文件」
- 抖音 Tab：textarea + 主题输入 + 提交按钮
- 文件 Tab：类型选择(视频/音频/文档) + 标题 + 主题 + 文件选择 + 上传按钮
- 提交后显示 event_id，附跳转链接到 /events

### 事件列表 `/events`
- 每项：标题、摘要(200字截断)、来源(source_id)、状态 pill、时间
- 筛选栏：状态下拉 / 来源下拉 / 主题下拉
- 分页：暂无，全部加载（事件量初期可控）

### 信息源 `/sources`
- 每行：名称、URL、类型、主题、优先级、状态(启用/停用)、最近采集时间

### 摘要 `/digest`
- 日期 + 使用事件数 + 行动候选数 + markdown 正文

### 行动候选 `/candidates`
- 每项：标题、建议行动、推荐角色、状态
- 操作：确认行动 / 忽略 / 标记已处理

## 数据流

- 每个页面独立调用自己的 API，不跨页面共享数据
- 页面内状态（表单、筛选）本地管理
- 导航触发 API 重载即可

## 技术实现

- 依赖新增：`react-router-dom` v6
- 不改后端 API，纯前端重构
- 构建命令不变：`npm run build`
- 入口文件：`App.tsx` 作为 layout shell，`pages/` 目录下每个页面独立文件

## 非目标（本次不做）

- 深色/亮色主题切换
- 移动端适配（现有 responsive 保留但非重点）
- 实时 WebSocket 推送
- 用户认证 / 权限
- 分页 / 虚拟滚动

## 验收标准

1. 每个导航项点击 → URL 变化 → 页面内容切换（非滚动）
2. 浏览器后退/前进正常工作
3. 指标卡片带 emoji 图标
4. 按钮 / 输入 / 列表 / 空状态样式统一
5. 提交抖音分享 → 跳转事件列表可看到新事件
6. 所有现有 API 端点正常工作
